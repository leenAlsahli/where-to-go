A smart tourism web application designed to help users discover and book local events across Saudi Arabia based on their current mood.

## Overview
Where To Go reimagines event discovery through the lens of mood rather than just category or location. The platform lets users browse events, filter them by mood, save favorites, and complete a simple booking flow — all wrapped in a mood-responsive interface that shifts between Light, Dark, and Natural themes to match the experience being offered.

## Features
- Mood-based user interface (Light / Dark / Natural themes)
- User registration and login
- Browse and search events
- Filter events by mood
- Add events to favorites
- View detailed event information
- Booking confirmation screen
- Profile page with user information

## Tech Stack
- **Frontend:** Vue.js
- **Build Tools:** Vite, Node.js
- **Styling:** CSS
- **Hosting:** GitHub

## How It Works
1. Users register or log in to access personalized features like favorites and bookings.
2. The homepage presents events tied to different moods, with theme switching (Light / Dark / Natural) reflecting the selected atmosphere.
3. Users can search, filter by mood, view event details, and save favorites for later.
4. Selecting an event leads to a straightforward booking flow ending in a confirmation screen.

## Running Locally
```bash
npm install
npm run dev
```

## What I Learned
Building Where To Go focused on translating an abstract concept — mood — into concrete UI and filtering logic, while following end-to-end software engineering practices around usability, scalability, and user-centered design throughout the development lifecycle.
